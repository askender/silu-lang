C 互操作与自举工具链

Silu 互操作有两扇门：@export（Silu 函数变成 C 符号，被 C/Rust 宿主链接调用）和 from c import（Silu 声明并调用外部 C 函数）。 配合自举工具链 siluc（一行命令、零 Python），完整用法如下。

编译命令总览

# ① 自举管线（推荐）：siluc C 驱动 + siluc1 原生编译器 + clang
./siluc program.si -o program          # 一行，零 Python，0.13s

# ② 产出可链接对象 + 自动生成 C 头文件
./siluc lib.si -o lib.o --object       # 产出 lib.o + lib.o.h

# ③ Python 编译器（开发/调试用）
python -m silu build program.si -o program

# ④ 完全手动、零 Python 的底层管道（会全量编译运行时，慢）
./silu_fe < program.si | ./silu_conv > program.ll
clang -O2 program.ll -lm -o program

发布压缩包已包含 siluc 与 siluc1，请保持两者位于同一目录。 运行时 .o 缓存在 $XDG_CACHE_HOME/silu-runtime/driver/（未设置时为 ~/.cache/silu-runtime/driver/），冷缓存一次性 ~0.4s。

方向 1：Silu → C 库（@export）

# lib.si
@export
def fib(n: int) -> int:
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)

@export
def circle_area(r: float) -> float:
    return 3.14159 * r * r
./siluc lib.si -o libfib.o --object   # 产出 libfib.o 和 libfib.o.h

生成的头文件（节选）：

/* generated by siluc --object */
#include <stdint.h>
#include <stdbool.h>
typedef struct { int32_t tag; void* data; } PObj;
int64_t fib(int64_t);
double circle_area(double);

C 宿主：

#include <stdio.h>
#include "libfib.o.h"
int main(void) {
    printf("%lld\n", (long long)fib(24));   // 46368
}
clang -O2 host.c libfib.o -lm -o host && ./host

Rust 宿主：

use std::os::raw::c_longlong;
extern "C" { fn fib(n: c_longlong) -> c_longlong; }
fn main() { unsafe { println!("{}", fib(24)); } }
clang -shared libfib.o -lm -o libfib.dylib
rustc -C opt-level=3 host.rs -o host -C link-arg=-L/dir -C link-arg=-lfib -C link-arg=-lm

类型映射：int ↔ int64_t、float ↔ double、bool ↔ bool； 静态标量签名天然就是 C 签名（LLVM 类型系统同构）。动态函数 （含 pyobj 参数/返回）以 PObj* 稳定盒指针传递——C 侧按 tag 读取（0=int 1=float 2=str 4=list 5=dict 6=instance 8=set）。 --object 产物含全部运行时（自包含 .o，宿主无需额外依赖）。

方向 2：C → Silu（from c import）

from c import sqrt, floor, pow, strlen

x: float = sqrt(2.0)        # 1.4142135623730951
print(floor(3.7))           # 3.0
print(pow(2.0, 10.0))       # 1024.0
s: str = "hello"
print(strlen(s))            # 5
  • 转换器按调用点参数类型发射 declare（float 参数 → double

签名）；与运行时已有声明同名时自动复用。

  • str 参数以 const char* 传递（NUL 终止拷贝；C 侧不得释放）。
  • 解释器平面自动绑定 ctypes 精确 libc 签名，CPython 平面（pycompat）

提供 c 模块——同一源码四平面一致。

  • 动态值不跨边界（编译期明确报错）：extern 是静态世界的大门。
