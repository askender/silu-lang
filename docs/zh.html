给出证明，或者给出反例

⚡

真正的证明，不是采样

a / (b*b + 1) 被证明安全——Z3 通过代数推理得出除数恒 ≥ 1，覆盖所有可能的输入。模糊测试说不出这句话。

🎯

真实 bug 的反例

m / (n - n) 被标记为可达崩溃，并给出触发输入——因为除数恒等于零。你拿到的是具体的崩溃参数，不只是警告。

🔗

契约可组合

require(b != 0) 声明函数的定义域。函数独立证明安全；调用点另行检查是否尊重契约。删除任何调用方不会影响函数自身的证明。

当前范围：除零、列表/字符串下标越界、字典键。循环按有限界验证；求解器无法判定的义务会被明确报告为未证明——绝不静默视为安全。

$ cat safe.si
def safe_div(a: int, b: int) -> int:
    require(b != 0)
    return a / b
 
$ silu prove safe.si
safe_div: ok (1 checked abort site(s) proved safe)
verify: ok - no abort reachable
 
$ cat buggy.si
def risky(m: int, n: int) -> int:
    return m / (n - n)
 
$ silu prove buggy.si
risky: POSSIBLE ABORT - division by zero
verify: ABORT REACHABLE

自举，而且可以证明这一点

编译器用 Silu 自己写的

词法分析、语法分析、IR 生成器、LLVM 代码生成——全部用 Silu 编写，并被自身编译为原生二进制。不动点检查（自举转换器逐字节复现自己的构建输出）在测试套件中持续运行。

一条命令完成自举

silu bootstrap 从源码构建零 Python 工具链，约 25 秒。之后每次编译只需 ./siluc file.si -o prog——0.11 秒，默认 LTO。

所有权，无 GC

静态注解决定内存表示：int 留在栈上，str 是作用域退出时释放的独占缓冲，容器无装箱。赋值即所有权转移。取舍——包括当前刻意从简的动态平面——写在内存文档里。
