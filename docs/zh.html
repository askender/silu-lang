证明器

⚡

真正的证明，不是采样

a / (b*b + 1) 被证明安全——Z3 通过代数推理得出除数恒 ≥ 1，覆盖所有可能的输入。

🎯

真实 bug 的反例

m / (n - n) 被标记为可达崩溃，并给出触发输入——因为除数恒等于零。你拿到的是具体的崩溃参数，不只是警告。

🔗

契约可组合

require(b != 0) 声明函数的定义域。函数独立证明安全；调用点另行检查是否尊重契约。删除任何调用方不会影响函数自身的证明。

$ cat safe.si
def safe_div(a: int, b: int) -> int:
    require(b != 0)
    return a / b
 
$ silu prove safe.si
safe_div: ok (1 checked abort site(s) proved safe)
verify: ok - no abort reachable
 
$ cat buggy.si
def risky(m: int, n: int) -> int:
    return m / (n - n)
 
$ silu prove buggy.si
risky: POSSIBLE ABORT - division by zero
verify: ABORT REACHABLE

自举编译器

编译器用 Silu 自己写的

词法分析、语法分析、IR 生成器、LLVM 代码生成——全部用 Silu 编写，并被自身编译为原生二进制。不动点证明（自举转换器逐字节复现自己的构建输出）在测试套件中持续运行。

一条命令完成自举

silu bootstrap 从源码构建零 Python 工具链，约 25 秒。之后每次编译只需 ./siluc file.si -o prog——0.11 秒，默认 LTO。

无 GC，无借用检查器

静态类型注解决定内存表示：int 留在栈上，str 使用 Rust String 风格的独占缓冲，容器使用无装箱的原始存储。纪律在编译器里，不在程序员身上。
