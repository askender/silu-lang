Prove, or get the counterexample

⚡

Real proofs, not sampling

a / (b*b + 1) is proved safe by algebraic reasoning — the divisor is always ≥ 1, over all possible inputs. Fuzzing can't say that.

🎯

Witnesses for real bugs

m / (n - n) is flagged with a counterexample — the divisor is identically zero. You get the crashing input, not just a warning.

🔗

Contracts compose

require(b != 0) declares a function's domain. The function proves safe standalone; callers are checked separately. Removing a caller never invalidates anything.

Scope today: division by zero, list/string index bounds, dict keys. Loops are verified to a fixed bound; obligations the solver cannot discharge are reported as unproved — never silently assumed safe.

$ cat safe.si
def safe_div(a: int, b: int) -> int:
    require(b != 0)
    return a / b
 
$ silu prove safe.si
safe_div: ok (1 checked abort site(s) proved safe)
verify: ok - no abort reachable
 
$ cat buggy.si
def risky(m: int, n: int) -> int:
    return m / (n - n)
 
$ silu prove buggy.si
risky: POSSIBLE ABORT - division by zero
verify: ABORT REACHABLE

Self-hosted, and it can prove that

The compiler is written in Silu

Lexer, parser, IR generator, LLVM code generator — all Silu, compiled to a native binary by itself. The fixed-point check — the self-hosted converter reproducing its own build output byte-for-byte — runs in the test suite.

One command bootstrap

silu bootstrap builds the zero-Python toolchain from source in ~25 seconds. After that, every compile is ./siluc file.si -o prog — 0.11 seconds, LTO by default.

Ownership, no GC

Static annotations decide representation: int lives on the stack, str is an owned buffer dropped at scope exit, containers are unboxed. Assignment transfers ownership. The trade-offs — including today's deliberately simple dynamic plane — are written up in the memory doc.
