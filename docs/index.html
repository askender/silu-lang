The Prover

⚡

Real proofs, not sampling

a / (b*b + 1) is proved safe by algebraic reasoning — the divisor is always ≥ 1. Z3 discharges the obligation over ALL inputs.

🎯

Witnesses for real bugs

m / (n - n) is flagged with a counterexample — the divisor is identically zero. You get the input that crashes, not just a warning.

🔗

Contracts compose

require(b != 0) declares a function's domain. The function proves safe standalone; callers are checked separately. Removing a caller never invalidates anything.

$ cat safe.si
def safe_div(a: int, b: int) -> int:
    require(b != 0)
    return a / b
 
$ silu prove safe.si
safe_div: ok (1 checked abort site(s) proved safe)
verify: ok - no abort reachable
 
$ cat buggy.si
def risky(m: int, n: int) -> int:
    return m / (n - n)
 
$ silu prove buggy.si
risky: POSSIBLE ABORT - division by zero
verify: ABORT REACHABLE

Self-Hosted

The compiler is written in Silu

Lexer, parser, IR generator, LLVM code generator — all Silu, compiled to a native binary by itself. The fixed-point proof (the self-hosted converter reproducing its own build output byte-for-byte) runs in the test suite.

One command bootstrap

silu bootstrap builds the zero-Python toolchain from source in ~25 seconds. After that, every compile is ./siluc file.si -o prog — 0.11 seconds, LTO by default, no Python anywhere in the pipeline.

Memory without GC or borrow checker

Static type annotations drive the representation: int stays on the stack, str gets a Rust-String-style owned buffer, containers use unboxed raw storage. The discipline is in the compiler, not the programmer.
